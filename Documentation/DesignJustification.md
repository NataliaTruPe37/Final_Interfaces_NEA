The app was developed based on two principles:

- Law of Similarity: Users associate elements that look similar the same group; in this case, any green button indicates to the user to continue, while red colors indicate a block or a step back.

![Imagen](./imagenes/imagen_01.png)

![Imagen](./imagenes/imagen_02.png)

![Imagen](./imagenes/imagen_03.png)

- Von Restorf Effect: An element that stands out from its surroundings is easier to remember. In this case, all the buttons we've used are red or green, but the button for adding expenses is yellow and considerably larger, which makes it easy for the user to remember it quickly.

![Imagen](./imagenes/imagen_04.png)

- Constantly Feedback: This isn’t a psychological law, but a interface principle, we constantly tell the user the consequences of the decisions their making while managing their expenses.
